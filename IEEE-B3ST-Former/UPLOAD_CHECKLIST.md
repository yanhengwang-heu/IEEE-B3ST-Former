# GitHub Upload Checklist

Before making the repository public, please check:

- [ ] Choose a real open-source license and replace the placeholder `LICENSE`.
- [ ] Confirm the repository URL matches the manuscript URL.
- [ ] Do not upload raw datasets, checkpoints, temporary outputs, or manuscript files.
- [ ] Check the dataset download links in the paper and README.
- [ ] Add citation information after the paper is accepted or assigned a DOI.
- [ ] Run a smoke test after cloning the repository in a clean environment.

Suggested repository name:

```text
IEEE-B3ST-Former
```
